    ca

    • kevin ca install
    • kevin ca uninstall

    kevin ca#

    Manages the kevin root CA in the trust stores of this machine. It needs no project - the root names none and is shared by every kevin project on the machine. See the CA and trust guide for the full picture.

    kevin ca install#

    Generates the kevin root CA if it does not already exist, then adds it to the trust stores of this machine. Run this once for the machine; there is no need to repeat it per project.

    kevin ca install
    FlagTypeDefaultDescription
    --firefoxbooltruealso install into every Firefox profile’s NSS database
    --systemboolfalseinstall into the machine-wide store instead of the store of the user; needs root

    kevin ca uninstall#

    Removes the kevin root CA from the trust stores of this machine.

    kevin ca uninstall
    FlagTypeDefaultDescription
    --firefoxbooltruealso remove from every Firefox profile’s NSS database
    --systemboolfalseremove from the machine-wide store instead of the store of the user; needs root
