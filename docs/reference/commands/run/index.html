    run

    kevin run#

    Creates the environment’s env steps in dependency order, then blocks until an interrupt. On Ctrl-C, run removes the steps in reverse order.

    kevin run
kevin run --keep --open
    FlagTypeDefaultDescription
    --keepboolfalseleave the environment in place on exit
    --openboolfalseopen the console in the default browser once it’s listening

    See Configuring an environment for what an env step is.
