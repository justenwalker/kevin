    kevin plugin#

    Packages, publishes, finds, and trusts plugins. See Third-party plugins and Publishing a plugin.

    kevin plugin pack <dir>#

    Creates a plugin package (.tar.gz) from the files in dir, and writes its manifest.json. If dir has a manifest.json, the flags replace its fields. If it has none, the flags must supply every field.

    kevin plugin pack ./my-plugin -o my-plugin.tar.gz
    FlagTypeDefaultDescription
    --argsstringSlice[]default arguments for the entrypoint (overrides manifest.json)
    --authorstring-plugin author (overrides manifest.json)
    --descriptionstring-plugin description (overrides manifest.json)
    --entrypointstring-entrypoint path, relative to dir (overrides manifest.json)
    --namestring-plugin name (overrides manifest.json)
    --output, -ostring-Required. output tar.gz path
    --versionstring-plugin version (overrides manifest.json)

    kevin plugin push <tar.gz> <oci-ref>#

    Uploads a plugin package to an OCI registry, with the credentials from docker login. If <tar.gz>.minisig or <tar.gz>.sigstore.json exists, push uploads it too. The registry keeps one signature for each package, so push only one of them.

    kevin plugin push my-plugin.tar.gz ghcr.io/acme/plugin:v1

    kevin plugin trust#

    Manages the signers that kevin trusts for plugin packages with signing set. Minisign keys are in ~/.kevin/trusted-keys/, and sigstore identities in ~/.kevin/trusted-identities/. These are separate from the machine trust store that kevin ca manages.

    kevin plugin trust add <pubkey-file>#

    Trusts a minisign public key.

    kevin plugin trust list#

    Lists trusted keys and identities, with their scheme.

    kevin plugin trust remove <key-id>#

    Removes a minisign key.

    kevin plugin trust add-identity#

    Trusts a sigstore identity: the certificate identity (an email, or a GitHub Actions workflow URI) and the OIDC issuer URL.

    FlagTypeDefaultDescription
    --identitystring-Required. the trusted certificate identity (e.g. an email, or a GitHub Actions workflow-ref URI)
    --issuerstring-Required. the trusted OIDC issuer URL (e.g. https://token.actions.githubusercontent.com)

    kevin plugin trust remove-identity <identity> <issuer>#

    Removes a sigstore identity.

    kevin plugin index#

    Manages indexes: git repositories that list plugins and their releases.

    kevin plugin index add <git-url>#

    Adds an index, clones it, and prints the number of plugins in it. Adding an index that is already configured does nothing.

    FlagTypeDefaultDescription
    --asstring-alias for this source (default: derived from the URL)

    kevin plugin index list#

    Lists indexes, with their aliases and URLs.

    kevin plugin index remove <alias>#

    Removes an index and its local copy.

    kevin plugin index update#

    Clones each index again, and each version_source repository that its plugins name. An index that fails does not stop the others. A plugin whose version_source fails, or whose version file has no valid signature, gets its own warning. Exits non-zero if anything failed.

    kevin plugin index show <name-or-alias/name>#

    Prints the metadata and versions of a plugin, newest first, and the plugins: entry for the latest version. The latest version is the highest version without a pre-release suffix (see Plugin index format). If the name is in more than one index, use <alias>/<name>.

    FlagTypeDefaultDescription
    --versionstring-show this exact version’s snippet instead of the plugin’s metadata and version list

    kevin plugin index install <name-or-alias/name>#

    Trusts the signers that the plugin’s index entry declares for the version’s signing scheme, then adds the plugin’s plugins: entry to the environment file. If the index declares no signer for that scheme, install prints a warning and still adds the entry.

    Fails if the environment file already declares the plugin, or is not a single CUE file without a package clause. In that case, copy the entry from show.

    FlagTypeDefaultDescription
    --no-trustboolfalseskip adding the signer to the local trust store
    --versionstring-install this exact version instead of the latest

    kevin plugin search [query]#

    Searches the names and summaries of plugins in every index. The search ignores case. With no query, lists every plugin. Each result shows <alias>/<name>, the summary, and the latest version.
