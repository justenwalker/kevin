# Extending kevin

This section is for writing a new plugin: a new step type as a separate binary, with no change to kevin itself. [Writing a plugin]({{< relref "writing-a-plugin" >}}) is the how-to; [The plugin protocol]({{< relref "plugin-protocol" >}}) is the wire contract it rides on. Read [Concepts]({{< relref "/docs/concepts" >}}) first for the engine's DAG, proxy, and CA model. If you're using kevin to run an environment, you want [Quickstart]({{< relref "/docs/quickstart" >}}), [Guides]({{< relref "/docs/guides" >}}), or [Reference]({{< relref "/docs/reference" >}}) instead. If you want to build or contribute to kevin itself, see [Contributing]({{< relref "/docs/contributing" >}}).
