# Extending kevin

Add a step type to kevin with a plugin: a separate program, with no change to kevin.

- [Writing a plugin]({{< relref "writing-a-plugin" >}}): build a plugin in Go.
- [The plugin protocol]({{< relref "plugin-protocol" >}}): the gRPC service that a plugin implements.
- [Publishing a plugin]({{< relref "publishing-a-plugin" >}}): package, sign, and share a plugin.

To build or change kevin itself, see [Contributing]({{< relref "/docs/contributing" >}}).
