# Reference

The `with` block config for every builtin step type, generated from each step's `#Config` CUE schema. `!` marks a required field, `?` an optional one, `| *value` a default. See [CEL expressions]({{< relref "/docs/cel-expressions" >}}) for the `${...}` syntax used inside `with` values.
